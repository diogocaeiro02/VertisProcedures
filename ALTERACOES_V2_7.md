# Alterações v2.7

- Adicionada a fase “Pagamento intermédio”.
- Adjudicação, pagamento intermédio e pagamento final são configuráveis.
- Validação para garantir que as fases totalizam 100%.
- O regime de IVA deixou de estar limitado a opções predefinidas.
- É possível adicionar qualquer taxa de IVA.
- Cada taxa recebe uma percentagem configurável da base tributável.
- Validação para garantir que a distribuição do IVA totaliza 100%.
- Resultados detalhados por fase e por taxa.
- Cache atualizado para a versão 2.7.0.
